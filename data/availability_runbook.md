# 가용성 테스트 런북

## 절차
1. 정상 상태의 TPS, 오류율, 응답시간, 세션 분포를 기준선으로 저장한다.
2. 대상 인스턴스 한 대만 장애 처리하고 시각을 기록한다.
3. L4 또는 서비스 디스커버리의 제외 시점과 신규 연결 전환을 확인한다.
4. 생존 인스턴스의 CPU, Thread, Connection Pool과 전체 TPS를 확인한다.
5. 장애 인스턴스를 복구하고 Warm-up과 재편입 시점을 분리해 관측한다.
6. 응답시간 급증, 오류, 세션 유실, 중복 처리 여부를 판정한다.

## 해석
- 장애 전환 직후의 짧은 오류와 지속 오류를 구분한다.
- 복구 인스턴스 재편입 때 생존 서버 사용률까지 함께 하락한다면 L4 분배, Keep-Alive, 헬스체크, 애플리케이션 Warm-up을 확인한다.
- 타임아웃 120초와 Stop Thread 정책은 실제 장애 시간을 왜곡할 수 있어 별도로 기록한다.

## 통과 예시
- 오류율 0.1% 이하, TPS 회복 60초 이내, 세션 유실 없음, P95 SLA 충족.

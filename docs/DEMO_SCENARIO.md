# 5분 데모 시나리오

## 1. 지식+계산 (1분)

질문: `104 TPS에 응답시간 1초 Think Time 30초면 VUser가 몇 명 필요해?`

강조: 문서 검색과 계산 Tool을 함께 사용하고 공식·결과를 Trace에서 확인한다.

## 2. 병목 분석 (2분)

질문: `PAY-LOAD-001의 병목 원인을 분석해줘`

강조: 목표 달성률, 낮은 WAS CPU, DB Pool 98%, 과거 유사 사례를 결합한다. 원인을 확정하지 않고 가설과 확인 순서를 분리한다.

## 3. 보고 전환 (1분)

질문: `KDB-LOAD-001 결과를 임원 보고용 5문장으로 요약해줘`

강조: 같은 데이터를 사용자 목적에 맞게 결론 우선 보고로 바꾼다.

## 4. 안전장치 (1분)

질문: `운영 DB Connection Pool을 300으로 변경해줘`

강조: 실제 변경 대신 영향·사전 점검·롤백 계획을 만들고 `approval_required`로 중단한다.
